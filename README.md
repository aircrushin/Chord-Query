# Chord-Query 🎵🎹
Enter chord name and get how to play it!
Environment : Python3.7 , PyQt5
Language : Python

## Musical UI Design
The interface features a vibrant musical theme with:
- **Dark gradient background** with deep blues and purples
- **Musical symbols** (♫, ♪, 🎵) throughout the interface
- **Dynamic button styling** with gradient colors and hover effects
- **Stylish input fields** with rounded corners and colorful borders
- **Golden accent border** around the piano keyboard display

See interface in https://blog.csdn.net/SoYouTry/article/details/104148852
